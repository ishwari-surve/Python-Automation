## Key Projects

### Data Shield
-Secure file monitoring solution implementing checksum-based validation

-Real-time file protection and verification system

### Checksum Calculator

-Verifies data authenticity and file integrity
-Support for multiple hashing standards

### CPU Log Monitor
-Real-time system resource tracking application
-Logs processor utilization metrics and performance analytics
-Generates system performance reports

-Provides storage management recommendations
